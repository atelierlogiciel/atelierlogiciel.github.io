⬇ Télécharger Budget Pro

🔒 Le fichier est protégé par un mot de passe, réservé aux lecteurs : vous le trouverez au chapitre 3 du livre, dans la section « Récupérer le logiciel ».

Ouvrir le fichier téléchargé

  1. Le fichier budget-pro.zip arrive dans votre dossier Téléchargements.
  2. Faites un clic droit dessus, choisissez Extraire tout, puis cliquez sur Extraire.
  3. Windows demande le mot de passe : tapez celui du livre, puis OK.
  4. Rangez le dossier budget-pro obtenu dans Documents, puis suivez le livre, chapitre 3.
